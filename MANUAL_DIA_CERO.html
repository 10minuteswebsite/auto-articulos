Manual del Día Cero v3

Versión HTML generada desde el manual v3. El Día Cero separa Artículos y Redes conservando el login actual; el HUB funciona en paralelo.

Preparación

  1. Milton decide fecha.
  2. Mario crea los DNS nuevos.
  3. Configurar las variables de cookies y OAuth solo si se aprueba.
  4. Probar login, conexiones, MCP y Acceder como.
  5. Simular permisos de Redes y revisar conteos.

Día Cero

  1. Congelar y comprobar DNS.
  2. Encender permisos de Redes sin tocar excepciones.
  3. Activar la vista por productos.
  4. Mantener enforcement apagado.
  5. Probar router y OAuth desde ambos subdominios.
  6. Ejecutar smoke test y bitácora.

Reversa

Quitar las variables de entorno revierte cookies y callbacks; restaurar el respaldo SQL revierte permisos; quitar la vista revierte la separación visual. No se construye login HUB ni se redirige el dominio canónico.
