# FAQ de soporte — Día Cero

Documento B.5 de C-046. Respuestas cortas para soporte. No pedir contraseñas, tokens ni capturas con secretos.

**No veo Artículos. ¿Se borró mi cuenta?**

No. Tus datos no se borran por este cambio. Revisa “Mi acceso” y dinos qué pantalla ves.

**No veo Redes. ¿Qué hago?**

La cuenta puede no tener Redes activado o no tener una red aprobada. Envíanos la hora y el mensaje exacto; no desconectes nada.

**Me aparece “No tienes acceso”.**

No intentes crear otra cuenta. Soporte debe revisar el producto asignado y el estado de acceso de tu cuenta.

**La página se queda cargando.**

Recarga una vez. Si continúa, anota la URL, la hora y el navegador. No borres cookies ni cierres conexiones todavía.

**Una conexión de Google, Bing o una red pide reconectar.**

No reconectes varias veces. Indica el proveedor, la hora y el mensaje; soporte verificará el callback correcto.

**Veo artículos y publicaciones mezclados en Historial.**

Historial y Progreso todavía pueden mostrar ambos productos juntos. No significa que otra persona tenga acceso a tus datos.

**Soy administrador y estoy actuando como otra cuenta.**

Confirma primero que ves el aviso “Actuando como”. Para revisar tus propios derechos, sal de esa vista y vuelve a entrar.

**¿Debo enviar mi contraseña o un código de Google?**

No. Soporte nunca necesita tu contraseña, token, cookie ni código de verificación.

**¿Puedo seguir trabajando si aparece un aviso?**

Sí, si la pantalla permite continuar. Si una operación falla, guarda el mensaje y no repitas muchas veces la publicación.

**¿Qué información debo enviar a soporte?**

Correo de la cuenta, URL, fecha y hora, producto (Artículos o Redes), proveedor si aplica, mensaje visible y navegador. Nunca incluyas secretos.

**¿Cómo se revierte un problema?**

Soporte registra el caso y lo escala. No borres datos ni desconectes proveedores: la reversa debe conservar artículos, redes y conexiones.
